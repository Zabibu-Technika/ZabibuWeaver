The gap

Agents say “done”. Almost none can show what that claim rests on.

Runs the checks

It runs the checks

Package scripts, tsc, Cargo, Go. A failing check goes back to the model for one bounded repair pass, then the receipt says what actually happened.

Independent

It knows who wrote the judge

If the turn edited a test, a test config, or the check command, the result is capped at partial. A green run you authored is not independent evidence.

Leaves a record

It leaves an artefact

Commands, exit codes, timing, output digests, the Canary analysis id, and every path touched. Not the output itself — a failing test can print a secret.

What is different

Four things most agents still miss.

01Memory

Decision memory

An append-only ledger of choices, rejections, constraints, and assumptions. Changing your mind supersedes an entry; it never deletes the reasoning trail. The active ones are injected into the prompt, bounded.

02Reversible

Undo that does not need git

Content-addressed checkpoints before every mutation. It restores edits, deletes files the call created, and refuses to guess when the workspace sweep was truncated. No git init on a slow disk.

03Pushback

Scope pushback

Before building, it reads the request for traps: a destructive verb aimed at a whole scope, credentials plus an outbound action, a dependency nobody asked for, three objectives bundled into one.

04The gate

A gate it cannot skip

Canary judges every change deterministically, in-process, from a hash-pinned engine. There is no flag that lets the agent approve its own work. A human signs the receipt, or it stays blocked.

Built for the machines people actually have

The network is not free. The grid is not steady. The laptop is not new.

Language

Language is not free either

The same meaning costs a median 1.88× more tokens in African languages on GPT-5's tokenizer — 7.4× for Amharic, 8.92× for N'Ko. Weaver's estimator charges non-Latin text honestly, so a context budget does not quietly run out.

Power

Power cuts are normal

Both ledgers are JSONL with torn-write repair. A half-written line costs one entry, not the memory. Checkpoints are written before the change, not after.

Workspace

One base, outside the system

Setup puts projects in one base workspace under your home directory. Writes resolve against it; -C is how you choose another. The agent does not default to your system files.

The claim

A green check you can inspect.

Verification is not a status message. It is a file with commands, exit codes, and hashes that outlives the chat window. Read one before you trust one.

Quickstart

No account. No key. No cloud required.

cd ZabibuWeaver
npm install
npm start
